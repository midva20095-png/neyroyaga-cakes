# НейроЯга — макеты для сахарной печати

Сервис: ИИ вырезает объект, меняет фон и рисует картинки, а сервер собирает из них PDF
для печати на сахарной бумаге в точных сантиметрах.

## Файлы проекта

| Файл | Куда | Зачем |
|------|------|-------|
| `main_cake.py` | Railway | Сервер: ИИ, кредиты, оплата, галерея, сборка PDF |
| `pdf_builder.py` | Railway | Раскладка на листы A4: размеры, круги, обводка, удаление фона |
| `main.py` | Railway | Запасной вход, если запускается `uvicorn main:app` |
| `requirements.txt`, `Procfile` | Railway | Зависимости и команда запуска |
| `static/index.html` | Railway | Интерфейс по адресу сервера |
| `gallery/` | Railway | Готовые макеты для галереи. Названия — в `gallery/titles.json` |
| `objects/` | Railway | Библиотека объектов для песочницы (SVG/PNG). Названия — в `objects/titles.json` |
| `backgrounds/` | Railway | Каталог фонов для песочницы. Названия — в `backgrounds/titles.json` |
| `tilda_block.html` | Tilda | Тот же интерфейс для вставки в блок T123 |
| `build_tilda.py` | локально | Пересобирает `tilda_block.html` из `static/index.html` |
| `theme_tilda.css` | локально | Неоновая тема блока Tilda. Если файл есть, сборщик берёт его как есть |
| `Code.gs` | Google-таблица | Скрипт таблицы: вход и кредиты |

## Развёртывание

1. Загрузите все файлы, кроме `Code.gs`, в репозиторий и запустите деплой на Railway.
2. В Railway → Variables задайте: `GEMINI_API_KEY`, `GOOGLE_SCRIPT_URL`,
   `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`. Без них сервер работает в режиме разработки.
3. `Code.gs` вставьте в таблицу: Расширения → Apps Script → Развернуть как веб-приложение
   («Запуск от имени: Я», «Доступ: Все»), адрес `/exec` впишите в `GOOGLE_SCRIPT_URL`.
4. `tilda_block.html` вставьте в Tilda целиком, в блок «HTML-код».

## Цены

В `main_cake.py`, строка `PRICES` (1 кредит = 1 ₽):
готовый PDF или JPG без ИИ (песочница и раскладка) — 10; фон из каталога — 3;
работа ИИ — 50 (генерация, вырезка объекта, замена фона, улучшение макета);
доработка одной детали — 25.
Пакеты пополнения — `CREDIT_PACKS` там же. Цены считает только сервер.

## Что умеет интерфейс

- **Вырезать объект** — фото → объект на белом фоне. Можно сразу попросить надпись.
- **Заменить фон** — объект с одной картинки на фон с другой, формат 1:1, 9:16 и т. д.
- **Нарисовать ИИ** — картинка по описанию и стилю.
- **Вручную** — бесплатно, пять способов вырезать: прямоугольная рамка, овал, лассо по контуру,
  клик по объекту с подсветкой и «палочка» (клик по фону убирает его, чувствительность — ползунком).
- **Песочница** — сборка макета вручную: формат (круг 16/20/6 см, квадрат 10/16 см, A5, A4,
  свой размер с выбором формы), фон,
  объекты из библиотеки, свои картинки и результаты ИИ. Каждый объект двигается, меняет
  размер, поворачивается, отражается, копируется и переставляется по слоям.
  Надписи: текст с белой обводкой, любой шрифт и цвет — двигается и вращается как объект.
  Кнопка «Улучшить макет ИИ» (50 кр.) аккуратно поднимает качество, сохраняя композицию и надписи.
  Фон берётся из каталога `backgrounds` за 3 кр. и ложится под все объекты.
  Печать: один макет по центру листа или копии по листам; пресет «Капкейки: лист из 12 топперов
  6 см» ставит размер и количество сам. Формат файла — PDF или JPG 300 DPI.
  Лист — целый A4 или половина (210×148 мм) для печати на остатках бумаги.
- **Макет A4** — у каждой картинки свои размер, количество, обводка и форма (круг или по контуру).
  Режимы: набор наклеек, сетка под капкейки (12 кругов по 6 см), один макет точного размера.
- **Галерея** — готовые макеты из папки `gallery`, превью с водяным знаком, PDF за кредиты.
  Купленный макет открывается в песочнице кнопкой под результатом покупки — бесплатно.
  Отдельная кнопка «Открыть в песочнице» покупает макет сразу для доработки, без PDF.
- **Инструкция** — вкладка с полным описанием всех режимов, цен и правил печати. Там же
  кнопка «Показать демо»: студия сама соберёт пример макета в песочнице, ничего не списывая.

## Результат работы ИИ

После каждой операции ИИ под кнопками появляется карточка результата: превью, подпись куда
добавлено, кнопки «Открыть в песочнице» и «Сделать ещё раз».

## Печать

Печатать в масштабе 100% («Фактический размер»), не «по размеру страницы».
На каждом листе снизу есть линейка 100 мм для проверки.

## Если меняете интерфейс

Правьте `static/index.html`, затем `python build_tilda.py` и вставьте новый
`tilda_block.html` в Tilda. Адрес сервера задан в начале `build_tilda.py`.

## Как добавить свой объект или макет в галерею

Кладите файл в `objects/` или `gallery/` **именем на латинице** (например `shar-zolotoy.svg`),
а русское название впишите в `titles.json` той же папки:

```json
{ "shar-zolotoy.svg": "Шар золотой" }
```

Латиница в именах нужна, чтобы архив и репозиторий одинаково работали на macOS и Windows.
Если названия в `titles.json` нет, подписью станет имя файла.
