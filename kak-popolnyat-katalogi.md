# Как пополнять каталоги НейроЯги

В проекте три папки с картинками. Они устроены одинаково, поэтому правила общие.

| Папка | Что там лежит | Где видно на сайте |
|-------|----------------|--------------------|
| `objects/` | объекты для сборки: шары, звёзды, буквы, персонажи, рамки | вкладка «🧩 Песочница» → «Библиотека объектов» |
| `backgrounds/` | фоны для макета | вкладка «🧩 Песочница» → «Фон из каталога», 3 кр. |
| `gallery/` | готовые макеты на продажу | раздел «Галерея готовых макетов» внизу страницы |

---

## Шаг 1. Подготовьте картинку

**Для объектов (`objects`)**
- Формат: SVG, PNG или WEBP. Лучше SVG или PNG с прозрачным фоном.
- Размер PNG: от 1000 пикселей по большей стороне, иначе при печати будет мылко.
- Фон обязательно прозрачный, иначе вокруг объекта в макете будет белый прямоугольник.

**Для фонов (`backgrounds`)**
- Формат: PNG, JPG или WEBP.
- Размер: от 2000×2000 пикселей. Фон растягивается на весь макет, мелкая картинка расплывётся.
- Фон лучше брать квадратный: круглые макеты обрезают его по центру.

**Для галереи (`gallery`)**
- Формат: PNG, JPG или WEBP.
- Размер: от 2400 пикселей по большей стороне. Это товар, который печатают.
- Для круглых макетов делайте квадратную картинку: сервер обрежет её по центру.

---

## Шаг 2. Назовите файл латиницей

Имя файла — только латинские буквы, цифры и дефисы. Без пробелов и без кириллицы.

Правильно: `shar-zolotoy.svg`, `fon-akvarel-rozovyy.jpg`, `edinorog-s-sharami.png`
Неправильно: `Шар золотой.svg`, `фон 1.jpg`, `макет (2).png`

Кириллица в именах ломается при распаковке на разных компьютерах — файл просто пропадёт.

---

## Шаг 3. Положите файл в нужную папку

Прямо в папку, **без вложенных подпапок**. Сервер читает только верхний уровень:

```
objects/
├── titles.json
├── shar-krasnyy.svg
└── shar-zolotoy.svg      ← новый файл сюда
```

Папка `objects/novye/shar-zolotoy.svg` работать не будет.

---

## Шаг 4. Подпишите файл в titles.json

В каждой папке есть файл `titles.json` — это список русских названий. Откройте его
в редакторе и добавьте строку:

```json
{
 "shar-krasnyy.svg": "Шар красный",
 "shar-zolotoy.svg": "Шар золотой"
}
```

Правила:
- после каждой строки, кроме последней, ставится запятая;
- кавычки только двойные;
- слева имя файла с расширением, справа название для людей.

Если файла нет в `titles.json`, объект всё равно появится, но будет называться по имени
файла: `shar zolotoy`. Работать будет, выглядеть хуже.

**Первое слово названия — это группа для поиска.** «Шар красный», «Шар синий» и «Шар
золотой» все найдутся по слову «шар». Поэтому называйте однотипные вещи одинаково:
сначала предмет, потом уточнение.

---

## Шаг 5. Выгрузите на сервер

```
cd ~/Desktop/neyroyaga-cakes
```

Проверьте, что файлы на месте (число = картинки + titles.json):

```
ls objects | wc -l && ls backgrounds | wc -l && ls gallery | wc -l
```

Отправьте:

```
git add -A && git commit -m "new images" && git push
```

Railway задеплоит сам. Через минуту обновите страницу сайта — новые картинки появятся.

---

## Шаг 6. Проверьте на сайте

- Объект: вкладка «Песочница» → найдите его в поиске библиотеки по названию.
- Фон: вкладка «Песочница» → блок «Фон из каталога» → нажмите, спишется 3 кр.
- Макет: раздел «Галерея» → превью с водяным знаком, покупка даёт чистый PDF.

---

## Частые ошибки

| Симптом | Причина |
|---------|---------|
| Картинка не появилась | лежит в подпапке, а не прямо в `objects`/`backgrounds`/`gallery` |
| Название латиницей | файла нет в `titles.json` или там опечатка в имени |
| Каталог вообще пустой | папки нет на сервере: не сделан `git push` или файлы в `.gitignore` |
| Вокруг объекта белый квадрат | у PNG непрозрачный фон |
| На печати мыло | картинка меньше 1000 пикселей |
| Ошибка «Фон не найден» | имя файла и ключ в `titles.json` не совпадают |

## Сколько это стоит пользователю

| Действие | Цена |
|----------|------|
| Готовый PDF или JPG без ИИ | 10 кр. |
| Фон из каталога в песочницу | 3 кр. |
| Доработка одной вырезанной детали | 25 кр. |
| Генерация, вырезка объекта, замена фона, улучшение макета | 50 кр. |

Цены меняются в одном месте: строка `PRICES` в файле `main_cake.py`. После правки нужен
`git push`, чтобы Railway перезапустил сервер. Интерфейс берёт цены с сервера сам,
переписывать их в блоке Tilda не нужно.
